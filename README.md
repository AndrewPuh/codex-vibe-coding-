# NoOracle Lotto

Учебный прототип крипто-лотереи для **Ethereum Sepolia**.

- одностраничный сайт;
- подключение MetaMask;
- покупка билетов и розыгрыш;
- Solidity-контракт без Chainlink и внешних оракулов;
- намеренно слабая случайность из данных блока;
- demo-режим работает до деплоя контракта.

> **ТОЛЬКО TESTNET. НЕ ПРОХОДИЛО АУДИТ. НЕ ИСПОЛЬЗОВАТЬ С РЕАЛЬНЫМИ ДЕНЬГАМИ.** Владелец выбирает момент розыгрыша, а данные блока могут быть частично предсказуемыми или манипулируемыми.

## Деплой через Remix

1. Открыть `contract/NoOracleLottery.sol` в Remix.
2. Скомпилировать Solidity 0.8.x, совместимым с `^0.8.24`.
3. Выбрать Ethereum Sepolia в MetaMask.
4. Параметры конструктора:
   - `treasury_`: публичный адрес кошелька комиссии;
   - `ticketPrice_`: `1000000000000000` для 0.001 ETH;
   - `feeBps_`: `500` для 5%.
5. После деплоя вставить адрес контракта в `config.js` и установить `DEMO_MODE: false`.

Никогда не передавать seed phrase, private key, keystore или пароль MetaMask.
